# Fun Animation Playground ✨

A creative browser playground for designers and developers to experiment with particle-based animation styles, motion behaviors, and visual moods.

<img width="800" height="450" alt="ezgif-81f1dc0b4e85a462" src="https://github.com/user-attachments/assets/7af3b215-8272-47c4-9604-18deb4806449" />

This project is built for fast exploration: tweak controls, try different animation patterns, generate playful visual states, and export what you like.

🌐 You can also play with it online: [fun-animations.vercel.app](https://fun-animations.vercel.app/)

## Why This Exists 🎯

Designers can use it to:
- explore visual directions quickly
- test motion mood boards
- generate references for creative projects

Developers can use it to:
- learn animation patterns and timing behavior
- prototype UI/background motion ideas
- experiment with particle systems in real time

## What You Can Do 🚀

- Change background and particle colors
- Switch particle shapes (including fun animal-inspired shapes)
- Try multiple animation behavior modes
- Tune size, speed, and particle count
- Animate custom words
- Randomize full visual states with one click
- Export as PNG, GIF, or JSON preset

## Who It Is For 👥

- UI/UX designers looking for motion inspiration
- Frontend developers prototyping animation-heavy interfaces
- Creative coders who enjoy generative visuals
- Anyone who wants to play with animation and get cool results fast

## Run Locally 🛠️

This is a static web app.

1. Open the project folder.
2. Start a local server (any static server is fine).
3. Open `index.html` in your browser via that local server.

Example (Node):

```bash
npx serve .
```

## Project Structure 📁

- `index.html` - controls and app layout
- `styles.css` - visual styling and dashboard UI
- `app.js` - animation logic, behaviors, controls, and export handling
